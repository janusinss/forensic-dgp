# Unified CodeFormer Completion R2 V2 Design (`completion_codeformer_unified_r2_v2`)

## 1. Purpose, Baseline Provenance & Root-Cause Attribution from R2 v1

This specification defines **Trained CodeFormer Completion R2 V2** (`cctv_completion_codeformer_unified_r2_v2_vm`), continuing from incumbent **Trained CodeFormer Completion R1** (`terminal_training_state.pth`, SHA-256 `0a6b4ad907c6ead86d8f26d3446666387493cdce81c6adc1ed78a8677d50fadd`) after diagnostic attribution of `completion_codeformer_unified_r2_v1`:

1. **Modulo-4 Aliasing Fix in 128-Case Schedule (`orthogonal_balanced128_subset.json`)**:
   - In `balanced128_subset.json` (used by `PredCE` and `R2 v1`), `grayconditions[i % 2]` (period 2) and `rgbconditions[(i // 2) % 2]` (period 4) resonated with the 256-case pool's `(i + j) % 4` condition assignment, starving `('fit_anchor', 'eye_band')` (`8` vs `24` augmented) and `('fit_augmented', 'cheek_object')` (`8` vs `24` anchors, `0` RGB augmented cases), and grouping each 4-case microbatch into 4 copies of a single mask geometry.
   - `orthogonal_balanced128_subset.json` (`SHA-256: 0bb42287249693ab208fa1a609b263950cd3ebeec877480103d28f99b1f6c925`) uses `grayconditions[(i // 4) % 2]` (period 8) and `rgbconditions[(i // 8) % 2]` (period 16) with complementary pattern ordering `[0, 2, 1, 3, 4, 6, 5, 7]`.
   - Every `(role, mask_kind)` cell has **exact 16 cases**, every augmented `(condition, mask_kind)` cell has **exact 4 cases**, every 8-cycle snapshot window has **4 `fit_anchor` + 4 `fit_augmented` per geometry**, and **every single 4-case cycle (`1..32`) contains all 4 distinct geometries** (`1 lower_face, 1 eye_band, 1 image_left_lens, 1 cheek_object`), `2` `fit_anchor`, `1` `GRAY` `fit_augmented`, and `1` `RGB` `fit_augmented`.
2. **Damped Pre-Quant Latent Target Weight & Boundary-Transition Token Weighting**:
   - Because `prequant_latent` in `cached_teacher_labels/*.npz` was generated by the untrained base model (`codeformer_inpainting.pth`), `R2 v1`'s `1.0 * weighted_latent_mse` pulled `net.encoder` backward toward the pre-R1 encoder on Clear `eye_band`.
   - `R2 v2` damps `weighted_latent_mse` to `0.10` and decomposes the $16\times 16$ token support into observable inner-boundary ring (`1.0`), outer context ring (`0.50`), deep interior hole core (`0.10`), and visible context (`0.15`), preventing unobservable deep `lower_face` hole tokens from overfitting while strengthening `eye_band`, `image_left_lens`, and `cheek_object`.
3. **Interior Core + Hole + Seam + Gradient + Strict-Gray Chroma Fusion Objective**:
   - Incorporates `delivered256_core_L1` (`0.75` interior core L1 inside $m_{256} - b_{256}$, proven in `V3`) alongside `1.50` `delivered256_hole_L1`, `0.35` `delivered256_seam_L1`, `0.25` `delivered256_grad_L1`, `0.35` `raw512_hole_L1`, `0.20` `raw512_seam_L1`, and pairwise inter-channel chroma consistency (`0.35` RGB / `0.70` GRAY).
4. **Balanced Role Weights (`1.05` Anchor / `0.95` Augmented) & Cosine Schedule (`6e-6 -> 1.5e-6`)**:
   - Eliminates the `1.25 / 0.75` role-weight skew while maintaining clear-anchor trust-region regularization (`coef=2e-4`) toward $\theta_{\text{R1}}$ across all 332 trainable tensors.
