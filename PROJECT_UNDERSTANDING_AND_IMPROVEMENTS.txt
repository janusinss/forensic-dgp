1. EXECUTIVE SUMMARY & FORENSIC PROBLEM STATEMENT
================================================================================

1.1 The Operational Problem
Municipal CCTV cameras across Zamboanga City operate in high humidity, direct 
tropical sunlight, high-angle pole mounts, and severe network bandwidth constraints. 
Facial crops extracted from incident footage are typically:
  - Extremely low resolution (often sub-32x32 pixels)
  - Distorted by coarse H.264 / H.265 DCT block compression (macroblocking)
  - Blurred by subject transit motion and optical lens defocus
  - Corrupted by analog comb interlacing lines (NTSC/PAL 480i/576i coaxial feeds)
  - Degraded by high-ISO sensor thermal noise in night footage

1.2 The Forensic Admissibility Mandate (Philippine Rules on Electronic Evidence)
Commercial super-resolution tools (e.g., standard ESRGAN, CodeFormer, Stable Diffusion) 
invent new facial features ("AI hallucination"). Under A.M. No. 01-7-01-SC (Philippine 
Rules on Electronic Evidence), synthetic fabrication destroys digital chain-of-custody 
and invalidates surveillance evidence in court.

1.3 The Technical Solution
This project implements a Morphologically Constrained Deep Generative Prior (DGP):
  1. Lightweight MobileNetV2 Feature Pyramid Network (FPN) Generator
  2. 68-point Morphological FAN Loss ensuring generated outputs mathematically 
     preserve the suspect's true Euclidean landmark coordinates
  3. Top-K Probabilistic Sampling (Rank 1: Best Fit, Rank 2: Edge Focus, Rank 3: Natural Tone) 
     to provide investigators with a statistical spread of possible facial structures
  4. Local Air-Gapped FastAPI Web Application for on-premise forensic execution

4. CRITICAL RECENT FIXES (WHAT WAS SOLVED IN THIS SESSION)
================================================================================

4.1 Canonical Alignment Template Bug (Fixed)
  - Problem: Input faces appeared squinted, blurry, and over-zoomed in the Web UI, 
    whereas offline scripts previously produced sharp irises.
  - Root Cause: In degradation.py, dst_pts was set to an artificial 102.4px eye-distance 
    template (1.6x over-zoom). This forced the eyes outside the convolutional receptive 
    fields of the generator.
  - Fix Applied: Re-anchored dst_pts to standard FFHQ proportions:
      Left eye: [95.0, 118.0], Right eye: [161.0, 118.0] (66.0px eye distance).
    Pupil clarity, iris definition, and head framing were immediately restored.

4.2 Launcher Port 8000 Conflict / WinError 10013 (Fixed)
  - Problem: start.bat failed with "[WinError 10013] access forbidden by permissions".
  - Root Cause: A previous Python daemon process occupied port 8000 in TIME_WAIT.
  - Fix Applied: start.bat now runs an automated netstat taskkiller before launch:
      python -c "import subprocess, os; [os.system(f'taskkill /F /PID {line.strip().split()[-1]} >nul 2>&1') for line in subprocess.check_output('netstat -ano', shell=True).decode().splitlines() if ':8000' in line and 'LISTENING' in line]"

4.3 Terminal Noise Suppression (Fixed)
  - Handled GET /favicon.ico with a dedicated 204 No Content route in app.py.
  - Suppressed harmless PyTorch/FAN JIT UserWarning ("Compiling face alignment model").

4.4 Model Auto-Detection Priority (Fixed)
  - app.py now searches for checkpoints in this exact priority order:
      1. checkpoints/dgp_zamboanga_final.pth
      2. checkpoints/dgp_improved_epoch_26.pth down to epoch_1.pth
      3. weights/mapped_deblurgan.pth

4.5 Test Suite Organization (Cleaned)

5. QUALITY AUDIT: WHY `wild5.png` IS STILL SOFT
================================================================================

5.1 The Diagnosis
When testing test_images/wild5.png, the output is softer than synthetic_data_1.png.
  - Cause: wild5.png was subjected to artificial censorship-level Gaussian blur 
    (sigma approx 18 to 22 pixels), completely destroying high-frequency gradients.
  - In dataset.py, training blur was bounded at sigma <= 3.0 and d <= 10.
  - Under Charbonnier/L1 loss, when the network encounters out-of-distribution blur 
    where no high-frequency signal remains, the mathematically optimal prediction is 
    the smooth conditional average (conditional mean), avoiding risk of hallucination.

5.2 The 2 Proven Improvement Paths:

  PATH A: Test-Time Iterative Recurrent Pass (Immediate / In Web UI)
    - Concept: Feed Pass 1's reconstructed output back into the model for a second pass:
        Pass 1 -> Frequency Gradient Boost -> Pass 2 (Recurrent Refinement)
    - Experimental Result: In scratch/wild5_iterative_solution.png, Pass 2 successfully 
      resolves eye sockets, eyebrow ridges, nose bridge, and lip boundaries from the blob.
    - Implementation Location: app.py / generate_top_k(). Zero cloud GPU cost needed.

  PATH B: Phase 4 Retraining on GCP VM (Deep Defocus Inversion)
    - Expand blur spectrum in dataset.py:
        k_size: [3, 5, 7, 9, 11]
        sigma: [1.0, 10.0]
        displacement d: [4, 20]
    - Re-weight training loss in train.py:
        lambda_sobel: 0.5 -> 1.5 (heavily penalizes smooth/blurry edges)
        lambda_fft: 0.1 -> 0.4 (enforces high-frequency frequency domain power)
    - Resume from checkpoints/dgp_zamboanga_final.pth for 4-5 fine-tuning epochs (~12h).

6. HOW TO CONTINUE & RUN THIS IN A NEW WORKSPACE
================================================================================

6.1 Setup on a New Windows Machine
  1. Clone repository:
       git clone https://github.com/janusinss/forensic-dgp.git
       cd forensic-dgp
  2. Install environment:
       Double-click install.bat (or run: python -m venv venv; .\venv\Scripts\activate; pip install -r requirements.txt)
  3. Verify weights:
       Ensure checkpoints/dgp_zamboanga_final.pth exists (13.55 MB).
  4. Launch Web UI:
       Double-click start.bat
       Navigate to http://127.0.0.1:8000

6.2 Setup on a Linux / GCP Compute Engine Instance
  1. Clone and activate:
       git clone https://github.com/janusinss/forensic-dgp.git
       cd forensic-dgp
       python3 -m venv venv && source venv/bin/activate
       pip install -r requirements.txt
  2. Launch Web Server or Headless Tests:
       uvicorn app:app --host 0.0.0.0 --port 8000
  3. Run Batch Wild Inference Script:
       python scripts/test_wild_batch.py

6.3 How to Launch Phase 4 Retraining (If Chosen)
  1. Modify dataset.py (broaden blur) and train.py (increase lambda_sobel).
  2. Start tmux session:
       tmux new -s phase4
  3. Run training command:
       python train.py \
         --data_dir "dataset/thumbnails128x128,dataset/asian_faces" \
         --epochs 31 \
         --resume checkpoints/dgp_zamboanga_final.pth \
         --batch_size 16 \
         --lambda_sobel 1.5 \
         --lambda_fft 0.4
  4. Detach with Ctrl+B then D. Monitor with: tmux attach -t phase4.
