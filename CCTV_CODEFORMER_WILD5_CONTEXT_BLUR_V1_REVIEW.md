# Wild5: clearer generated output after blurring sharp surroundings

21 October 2026. The user requested a second test that approximately matches the sharp surroundings to wild5's already-blurred face. This test preserves the original face pixels. It is a controlled preprocessing observation on one unknown-source image, not training, model acceptance or evidence of correct recovered identity.

**Finding:** the surroundings-only input produces more readable generated eyes, nose and mouth in all four models. Untouched CodeFormer improves too. The earlier weaker whole-image blur also changed outputs favorably in this example. The strongest-looking row here blurs the surroundings, while the already-blurred input face remains unchanged. Output facial appearance can nevertheless change.
