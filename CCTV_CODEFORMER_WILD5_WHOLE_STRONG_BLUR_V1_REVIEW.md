# Wild5: stronger blur across the entire image tested

Later user decision on 21 October 2026 selects surroundings-only blur with the existing facial blur protected. This whole-image experiment remains historical evidence. [Refined surroundings test](CCTV_CODEFORMER_WILD5_PRECISE_SURROUNDINGS_V1_REVIEW.md).

21 October 2026. The user requested blurring **everything**, using the stronger blur level from the preceding surroundings-only experiment. A fixed Pillow GaussianBlur radius12.2578125 native pixels, nominal6 at256, was applied to the entire original455×523 RGB crop before unchanged app padding/resizing. It also blurs the already-blurred face again. The unknown original face kernel prevents a claim that every region has the same final effective blur.

**Observed result:** the whole-image version generates a more clearly defined face and eyes across all four restoration arms in this wild5 example. It also changes hairstyle and facial appearance more. The unknown clean original means neither sharpness nor plausibility establishes correct recovered facial detail or identity. Untouched CodeFormer changes too; this is preprocessing sensitivity, not a newly trained U96/S96 gain.
