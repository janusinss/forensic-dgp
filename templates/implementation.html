ONE FRONTAL OR MILD-TURN CROP

Conditioned SFT V2 (p2_u0224) workflow. Native CCTV usefulness and final acceptance remain under review. This page restores visible information; completion and covering removal are separate.

1. Inspect the original

Request a clearer or less-covered crop when the visible eyes, nose and mouth cannot be meaningfully inspected. A plausible sharper face is not proof of recovered identity.

2. Choose restoration

Auto assesses the original before optional preparation. You can override it. On uses one V2 inference call; Off uses none and skips preparation.

Globally soft, unknown or mixed inputs can bypass. Surroundings blur helped some examples but was mixed or adverse in the paired study. Automatic blur detection and matching remain unavailable.

3. Review Protect and Apply

Protect the complete face, existing blur and soft edges. Apply starts empty: paint only where added blur is permitted. Green wins overlap. Every protected pixel and every pixel outside Apply stays unchanged during preparation.

Paint or use the coordinate controls.

Start Protect with a rectangle

Manual Gaussian blur only, starting at radius 1. The preview adds an 8-pixel protection margin and a 16-pixel outside transition entirely within Apply. It rebuilds from the immutable original; previews never accumulate blur. No arbitrary noise, JPEG or mosaic is copied.

4. Restore the selected input

This sends one selected input to one model. It does not run covering detection or completion. Input protection applies only to preparation; the generated face can still change appearance.

5. Optional covering removal

No covering? Keep the restoration result above. For a covered face, review an automatic removal proposal before R1 estimates the hidden region. This separate step does not rerun or change V2 restoration.

The restoration result is ready for optional completion.

Review the removal area

Orange marks pixels R1 may replace. Automatic proposals can miss coverings or include visible features. Paint missed masks, sunglasses, strong glare, hands, obstructing hair, scarves or objects. Erase clear glasses, non-obstructing hair and visible features. Padding cannot be selected.

No removal pixels selected.

Paint a rectangle or import a binary mask

White means removal; black means preserve. The mask must contain only black and white pixels. Importing replaces the current removal area.

Use a clearer or less-covered crop when meaningful facial structure is unavailable. An empty reviewed area keeps the restoration result exactly and skips R1.

6. Review the plausible estimate

Completion preserves every restored input pixel outside the reviewed removal area. Restored pixels can differ from the original upload. Generated hidden features are estimates, not recovered identity.
