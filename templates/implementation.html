01 // FACE_INPUT

ONE FRONTAL OR MILD-TURN CROP

Experimental U96 workflow. Native CCTV usefulness and final acceptance remain under review. This page restores visible information; completion and covering removal are separate.

1. Inspect the original

Request a clearer or less-covered crop when the visible eyes, nose and mouth cannot be meaningfully inspected. A plausible sharper face is not proof of recovered identity.

2. Choose restoration

Auto assesses the original before optional preparation. You can override it. On uses one selected-model inference call; Off uses none and skips preparation.

Globally soft, unknown or mixed inputs can bypass. Surroundings blur helped some examples but was mixed or adverse in the paired study. Automatic blur detection and matching remain unavailable.

3. Review Protect and Apply

Protect the complete face, existing blur and soft edges. Apply starts empty: paint only where added blur is permitted. Green wins overlap. Every protected pixel and every pixel outside Apply stays unchanged during preparation.

Paint or use the coordinate controls.

Start Protect with a rectangle

Manual Gaussian blur only, starting at radius 1. The preview adds an 8-pixel protection margin and a 16-pixel outside transition entirely within Apply. It rebuilds from the immutable original; previews never accumulate blur. No arbitrary noise, JPEG or mosaic is copied.

4. Restore the selected input

This sends one selected input to one model. It does not run covering detection or completion. Input protection applies only to preparation; the generated face can still change appearance.
