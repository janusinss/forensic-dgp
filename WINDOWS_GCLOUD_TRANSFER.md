Install and configure the Windows CLI:

1. Download the [official Windows installer](https://dl.google.com/dl/cloudsdk/channels/rapid/GoogleCloudSDKInstaller.exe).
2. Run the installer with its default options, including bundled Python.
3. Open **Google Cloud SDK Shell** from the Windows Start menu after installation.
4. Verify the CLI:

   ```cmd
   gcloud --version
   ```

5. Initialize the configuration:

   ```cmd
   gcloud init
   ```

Use the account that owns/accesses the VM. The observed initialization prompts
have these answers:

| Prompt | Answer |

| Select project | `forensic-dgp-thesis`; choose by name because list numbers can change |
| Configure default Compute Region and Zone? | `N` |
| Zone list appears after accepting region setup | `1` — Do not set default zone |
| Create SSH keys/directory on the first transfer | `Y`; follow any remaining key prompts |

Successful initialization reports that the CLI is configured and ready.
[Official installation and initialization guide](https://docs.cloud.google.com/sdk/docs/install-sdk)

Download the full results from this VM:

1. Set the Windows destination directory:

   ```cmd
   cd /d "C:\xampp\htdocs\YEAR 4\Testing\outputs"
   ```

2. Download the archive as one remote source:

   ```cmd
   gcloud compute scp --project=forensic-dgp-thesis "janusdominic0@forensic-dgp-thesis:/home/janusdominic0/forensic-dgp/real_camera_vm_bundle/real-camera-results.tar.gz" .
   ```

3. Download the checksum as a separate remote source:

   ```cmd
   gcloud compute scp --project=forensic-dgp-thesis "janusdominic0@forensic-dgp-thesis:/home/janusdominic0/forensic-dgp/real_camera_vm_bundle/real-camera-results.tar.gz.sha256" .
   ```

4. Calculate the downloaded archive's SHA256:

   ```cmd
   certutil -hashfile "real-camera-results.tar.gz" SHA256
   ```

5. Display the expected SHA256:

   ```cmd
   type "real-camera-results.tar.gz.sha256"
   ```

The 64-character digest must match the calculated digest, ignoring letter case.
The checksum filename is not part of that comparison. A successful match verifies
the transfer against the supplied VM checksum, not independent training quality.
